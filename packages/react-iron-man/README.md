# react-iron-man

Iron Man flies around your React site, heckles your visitors, and plays catch with their real hand through the webcam.

Docs and live demo: https://ironman.kshitijbhardwaj.space

```bash
npm i react-iron-man
```

```tsx
import { Heroes } from "react-iron-man";

<Heroes />
```
